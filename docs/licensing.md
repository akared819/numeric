# Licensing decision pending

No project license has been selected. The GSL 2.8 mean implementation is GPL-3.0-or-later. The FSF considers a program linked with a GPL library a combined work subject to GPL terms on distribution; dynamic linking should not be assumed to remove those obligations. See the [GNU GPL FAQ](https://www.gnu.org/licenses/gpl-faq.html#IfLibraryIsGPL). Internal use and distribution have different implications.

A practical candidate for numeric is GPL-3.0-or-later if the copyright holders accept the intended distribution consequences. A GPL-compatible permissive license for numeric’s own code is another possible choice, but does not remove GSL obligations for a distributed linked combination. Confirm ownership and contributor permissions, intended distribution, corresponding-source and notice obligations, and compatibility of all bundled IOC components before choosing. EPICS Base uses the [EPICS Open License](https://epics-controls.org/epics-open-license/), which has its own notice requirements; other EPICS modules may use different licenses. Review the exact combined distribution with appropriate legal advice. No third-party source is vendored here.
