# Probability distributions

`normal_cdf` returns the lower-tail cumulative probability P(X ≤ x) for a standard normal random variable X with mean zero and standard deviation one. It calls GSL's [`gsl_cdf_ugaussian_P`](https://www.gnu.org/software/gsl/doc/html/randist.html#the-gaussian-distribution). Input and output are one DOUBLE scalar each; the input must be finite, its stride must be one and both buffers must have capacity for one value. For example, P(0) = 0.5 and P(1) is approximately 0.8413447460685429.

The GSL CDF function returns a value directly rather than a status. The adapter validates the input and checks that the result is finite and within [0, 1]. Invalid inputs, including NaN and infinities, return `InvalidArgument`; an invalid result returns `NumericalError`. Failure clears the output count and preserves the prior output value. Results are subject to floating-point rounding: very small lower-tail probabilities can underflow to zero and upper-tail values can round to one. No inverse or separate upper-tail calculation is provided by this operation.

The operation is stateless, has no random-number generator or workspace, and does not allocate during execution. Initialize the non-terminating GSL policy as described in [architecture](architecture.md#gsl-setup-for-an-ioc). The [numericScalar record](numeric-scalar.md) exposes OP `normal_cdf` through a scalar DOUBLE input; more than one element is rejected. In the standalone IOC, `demo:normalCdf` reads `demo:erfInput`. Write the input, explicitly process the record, and inspect VAL and SEVR. Failed calculations preserve VAL, clear NORD and raise CALC/INVALID.
