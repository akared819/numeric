# Architecture and public API

The intended layers are an EPICS interface, a numerical core, and thin GSL adapters. This increment implements the latter two only; an aSub interface and alarm mapping are future work. `numeric.h` is a preliminary C++ API, independently usable without an IOC. Interfaces may change before release.

Call `numeric::initializeGsl()` once during single-threaded process startup, before any thread invokes GSL, including other libraries. It disables GSL's process-global error handler using `gsl_set_error_handler_off`; this affects the entire process, not just numeric. The application must coordinate ownership of that global setting and must not change it concurrently or restore the terminating handler. GSL routines returning status codes must be checked by future adapters. The mean function returns a value rather than a status; its inputs and output are checked explicitly. See [GSL error handling](https://www.gnu.org/software/gsl/doc/html/err.html) and [statistics](https://www.gnu.org/software/gsl/doc/html/statistics.html).

A caller owns a registry, registers builtins, resolves metadata by name and creates an operation. Registry setup is single-threaded; do not mutate it while using it concurrently. Metadata pointers returned by `find` are invalidated by subsequent registrations or registry destruction. Metadata string pointers supplied to `add` must outlive the registry. Duplicate names and null factories are rejected. Each operation instance owns its own future resources via its virtual destructor; do not call an instance concurrently without external synchronization. `reset` provides a stateful lifecycle hook (no-op for mean). Future adapters must document workspace initialization, cleanup, callback lifetime and errors. Creation can allocate; execution of mean allocates no memory. Factory and registry allocation failures propagate C++ exceptions; an eventual C/EPICS boundary must catch them.

`mean` is stateless and takes one Float64 array and returns one Float64 scalar, with no parameters. It computes the arithmetic mean through `gsl_stats_mean`. Input count is the number of valid samples; capacity is the number of addressable doubles including gaps. Stride is measured in doubles. Output capacity is in doubles; on failure its count is zero when a single output descriptor is supplied, and its value is unchanged. Null buffers, zero counts/stride, insufficient capacity, wrong shapes and non-finite samples are rejected. A non-finite result is a numerical error. Caller owns buffers and keeps them valid throughout execution; no conversion, complex representation or multidimensional representation is defined. Error results carry a status and static message. Output values and counts must be checked before use.

Descriptors and operation signatures allow multiple inputs and outputs and scalar or array shapes. Stateful implementations and solver callbacks are not implemented; callback and parameter schemas require further design before exposure. No raw GSL workspace is exposed. There is no EPICS processing, input link triggering, or alarm behavior in this increment.
