# Architecture and public API

The intended layers are an EPICS interface, a numerical core, and thin GSL adapters. The aSub prototypes are documented in [aSub mean](asub-mean.md) and [streaming](streaming.md). `numeric.h` is a preliminary C++ API, independently usable without an IOC. Interfaces may change before release.

## GSL setup for an IOC

GSL's default error handler can terminate the entire IOC when certain errors occur. Add `numericInitialize` to the startup script after registering the IOC's record/device driver and before `iocInit` or other concurrent GSL use. Numeric then disables that terminating handler; its operations validate inputs and report errors instead. No separate GSL call is needed in the startup script.

This setting is shared by all GSL users in the same process. Another module may use GSL safely under the same policy, but if it installs or restores a different GSL error handler, that change also affects numeric. Check the other module's documentation or source if it changes the handler, and agree on a non-terminating handler before use. Separate IOC processes have independent settings. Numeric cannot detect a later replacement of the handler. Its initialization is idempotent and will not overwrite a later replacement.

For standalone core applications, call `numeric::initializeGsl()` once during single-threaded startup, before any thread invokes GSL. Every `Operation::execute` returns `NotInitialized` without calling its adapter until initialization completes. GSL routines returning status codes must be checked by future adapters. The mean function returns a value rather than a status; its inputs and output are checked explicitly. See [GSL error handling](https://www.gnu.org/software/gsl/doc/html/err.html) and [statistics](https://www.gnu.org/software/gsl/doc/html/statistics.html).

A caller owns a registry, registers builtins, resolves metadata by name and creates an operation. Registry setup is single-threaded; do not mutate it while using it concurrently. Metadata pointers returned by `find` are invalidated by subsequent registrations or registry destruction. The registry copies metadata strings and descriptors. Empty names, categories, parameter descriptions, lifecycle or error descriptions, missing input/output descriptors, invalid descriptors, duplicate names and null factories are rejected. Each operation instance owns its own future resources via its virtual destructor; do not call an instance concurrently without external synchronization. `reset` provides a stateful lifecycle hook (no-op for mean). Future adapters must document workspace initialization, cleanup, callback lifetime and errors. Creation can allocate; execution of mean allocates no memory. Factory and registry allocation failures propagate C++ exceptions; an eventual C/EPICS boundary must catch them. A factory may return a null pointer on failure; `create` also returns null for an unknown name. A factory owns any partially constructed resources until it returns, and operation destructors release instance resources.

`mean` is stateless and takes one Float64 array and returns one Float64 scalar, with no parameters. It computes the arithmetic mean through `gsl_stats_mean`. Input count is the number of valid samples; capacity is the number of addressable doubles including gaps. Stride is measured in doubles. Output capacity is in doubles; on failure its count is zero when a single output descriptor is supplied, and its value is unchanged. Null buffers, zero counts/stride, insufficient capacity, wrong shapes and non-finite samples are rejected. A non-finite result is a numerical error. Caller owns buffers and keeps them valid throughout execution; no conversion, complex representation or multidimensional representation is defined. Error results carry a status (`Ok`, `InvalidArgument`, `NumericalError`, or `NotInitialized`) and a static message. Output values and counts must be checked before use.

Descriptors and operation signatures allow multiple inputs and outputs and scalar or array shapes. The stateful running-mean implementation is described in [streaming](streaming.md); solver callbacks and parameter schemas require further design before exposure. No raw GSL workspace is exposed. The aSub mean prototype uses a shared stateless instance and explicit IOC startup; triggering and alarms are described in its documentation.
